About

I'm not a trainer. I'm a dad who made the time.

I'm Judson: husband, dad to two boys, and a guy with a full plate like everybody else. A little over a year ago I started getting up before the house did, because it was the only hour that was mine.

I started posting about it half as a joke. Then other dads started saying the same thing: "I don't have time." I get it. But if I can make it work, so can you.

This isn't about being an expert. It's about proving it can be done, and bringing a few more dads along with me.
